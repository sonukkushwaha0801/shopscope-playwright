# Security Policy

## Supported versions

Security fixes are currently applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not publish credentials, tokens, personal data, or exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if enabled; otherwise contact the repository maintainer privately through GitHub.

## Project-specific safeguards

- Never commit secrets, cookies, or browser storage state.
- Review screenshots, traces, and HTML reports before sharing; they can contain page content.
- Retailer or price-data integrations must use authorized APIs, licensed sources, or explicit permission.
- Do not bypass CAPTCHA, access controls, or rate limits.
